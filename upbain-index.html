Anti-flood center (Phase 3)

Mô phỏng 3 chiến lược gửi bài, so sánh flood và xem checklist chuẩn Telethon/Pyrogram/Bot API.

Checklist chống flood (chuẩn Telethon / Pyrogram / Bot API)

  • flood_sleep_threshold = 86400 · Telethon auto-sleep thay vì raise. Telethon docs
  • sleep_threshold ≥ 120s · Pyrogram cho window dài để retry tự động. Pyrogram docs
  • max_concurrent_transmissions ≤ 3 · Không đẩy quá cao, sẽ nghẽn connection pool.
  • Chunk upload ≤ 20 MB · Telegram giới hạn kích thước mỗi phần qua upload.saveFilePart. telegramhpc chunked upload
  • Idempotent retry · Server cache theo nội dung part, gửi lại không burn quota. Cùng message_id có thể retry an toàn.
  • Buffer +5s khi sleep · Tránh clock skew giữa client và Telegram khi retry FLOOD_WAIT_X.
  • Gửi theo batch · Gom 5–10 bài, nghỉ 1–2s giữa batch — giảm requests/sec xuống dưới ngưỡng.
  • Track lỗi flood · Ghi FLOOD_WAIT_X vào log, vẽ chart theo bot/topic để phát hiện pattern.
